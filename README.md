# Danai's Calendar

A paper-like planner and personal journal for iPad (Apple Pencil) and iPhone. Black and white; the only colour on screen is your own ink.

- SwiftUI + PencilKit, iOS/iPadOS 17+
- Free: no purchases, ads, analytics, accounts or servers. Your data stays on your devices and in your own iCloud.
- English and Greek

Built without a Mac: the project is described in `project.yml` (XcodeGen) and GitHub Actions builds, tests and takes simulator screenshots. See [docs/SPEC.md](docs/SPEC.md) for the product spec (in Greek).
